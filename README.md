# Velvet Cue Lounge (Demo)

Demo copy of the KS Tech snooker lounge booking and management system, with dummy data.
Used as a showcase on Black Diamond. It has its own separate Supabase database (no real client data).

## Pages

- `index.html` / `cafe-status.html`: public live table status page (3 languages)
- `book.html`: advanced booking form (shift, category, table, duration, WhatsApp confirm)
- `staff-dashboard.html`: staff dashboard (approvals, live tables, all bookings with Auto/Manual mode, snacks and drinks, reports with PDF/CSV, settings, testing)
- `policies.html`: club policies and privacy

## Demo logins

- Settings: password `settings2026`

## Stack

Static HTML + Supabase (database, realtime, storage, pg_cron) + Vercel.
